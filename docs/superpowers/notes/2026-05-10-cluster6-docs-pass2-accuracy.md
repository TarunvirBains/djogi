# Cluster 6 Docs Sweep — Pass 2: Docs-to-API Accuracy (2026-05-10)

> Self-review only. Independent GPT-5.5 xhigh review pending.

## Method

Enumerated all 103 `.md` / `.MD` files under `docs/` plus `ReadMe.MD` at HEAD
`63c2ce9`. Extracted Rust-fenced code blocks (217 across the 24 user-facing
guide files), inline `Type::method(` references, and relative cross-doc links.
For each surfaced API name, grepped the framework crates to confirm the type
and method exist with the documented signature. For each cross-doc link,
ran a Python walk that resolved relative paths and reported any non-existent
target. Anchor-existence inside Markdown headings was verified by hand for
the largest cross-link consumers (`docs/spec/maahi/` → `apps-and-database-domains.md#cross-app-fk-graph-t9`,
which resolves correctly to `## Cross-App FK Graph (T9)`). The proc-macro
emission surface (`{Model}Fields::field()`, `{Model}::filter()`, `{Visage}::from`)
is treated as believed-present unless a concrete usage exists.
