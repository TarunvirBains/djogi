# Cluster 6 Docs Sweep — Pass 3: Adopter Safety (2026-05-10)

> Self-review only. Independent GPT-5.5 xhigh review pending.

## Method

Catalogued every raw escape hatch defined in `djogi/src/__bypass.rs` plus the
`pub(crate)` underlying surfaces in `djogi/src/pg/pool.rs` and
`djogi/src/context.rs` at HEAD `63c2ce9`. For each definition site, read the
preceding rustdoc to confirm presence of (a) an "this is djogi's
`unsafe`-equivalent" warning, (b) a hyperlink to
`docs/spec/raw-sql-escape-hatches.md`, and (c) a pointer to the
`#[djogi::deliberately_bypass_convention_with_raw_sql]` attribute pattern.
Then grepped every `docs/guide/*.md`, `docs/spec/*.md`, and example file
that mentions the same method names to confirm the surrounding prose
classifies the call as an escape hatch with the same discipline. Cross-checked
the trait visibility (`#[doc(hidden)]` vs adopter-reachable) and the module-
level docstrings on `__bypass.rs`, `context.rs`, and `pg/pool.rs`. Counted
the spec-link cross-references inside `djogi/src/` (zero — see findings).
